
# Tema hijo pedro-hijo

## Descripción

Tema hijo de Twenty Twenty-Five utilizado en el blog SneakersHub. Permite personalizar el diseño del sitio sin modificar directamente los archivos del tema padre.

## Funcionalidades

- Paleta de colores y tipografía personalizadas mediante theme.json.
- Pie de página personalizado con nombre, curso y enlace a Contacto.
- Integración del shortcode [anio] en el pie de página.
- Estilos para la caja de contacto de las entradas.
- Ajustes para evitar desbordamientos en pantallas pequeñas.

## Instalación

1. Copiar la carpeta pedro-hijo en wp-content/themes/.
2. Comprobar que el tema Twenty Twenty-Five está instalado.
3. Acceder a Apariencia > Temas en WordPress.
4. Activar el tema hijo pedro-hijo.
5. Comprobar el diseño y el pie de página.

## Dependencias

- WordPress.
- Tema padre Twenty Twenty-Five.
- Plugin pedro-utilidades para ejecutar el shortcode [anio] y mostrar la caja de contacto.

## Archivos principales

- style.css: información del tema y estilos CSS.
- functions.php: carga de estilos.
- theme.json: colores y tipografía.
- parts/footer.html: estructura del pie de página.
